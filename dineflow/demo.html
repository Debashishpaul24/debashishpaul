📐 DineFlow Architecture & Real-Time Pipeline

DineFlow is engineered entirely with Vanilla JavaScript, the native BroadcastChannel API, and zero external runtime dependencies. Here is how dual-screen synchronization operates:

📱 Front-of-House (Guest)

Customer scans table QR code. In-memory cart dispatches orders via localStorage & BroadcastChannel with 5-stage live status tracking.

👨‍🍳 Back-of-House (KDS)

Kitchen Kanban receives instant broadcast tickets, synthesizes Web Audio concierge chimes, and updates floor matrix without page refreshes.

⚡ Zero Cloud Latency Inter-Frame Bus

Because both devices communicate over the browser's hardware-accelerated IPC bus (BroadcastChannel), state transitions occur at sub-millisecond speeds even with no internet connection.
