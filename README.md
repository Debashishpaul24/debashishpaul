# Debashish Paul — Personal Portfolio Website

A modern, high-performance personal portfolio website for **Debashish Paul**, Senior Software Engineer at TATA Consultancy Services (TCS), Ex-Software Engineer at Wipro Technologies.

---

## 🌟 Highlights & Features

- **3D Canvas Interactive Scroll Motion**: 240-frame 60fps canvas animation engine with LERP physics and nearest-neighbor frame fallbacks.
- **Fast Critical-Batch Preloader**: Rapid initial unlock with asynchronous idle frame streaming.
- **Automated Lead Capture Pipeline**: Native cross-origin Google Sheets integration with real-time Gmail lead notifications.
- **Global Country Code Flag Detection**: Real-time ISO flag badges for 240+ countries.
- **Interactive Social Proof & CTAs**: Testimonial slider, direct click-to-call integration, and floating Back to Top button.
- **Frosted Glassmorphism UI**: High-contrast dark luxury design system, responsive across desktop, tablet, and mobile.
- **Legal & Compliance Modals**: Accessible Privacy Policy & Terms of Service dialogs.

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3 (Modern Flexbox/Grid, Glassmorphism, CSS Custom Properties), JavaScript (ES6+)
- **Canvas Engine**: HTML5 2D Canvas with sub-pixel LERP smoothing
- **Integration**: Google Apps Script, Google Sheets API, Gmail API

---

## 🚀 Running Locally

You can launch the portfolio locally using PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Open `http://localhost:8080` in your web browser.
